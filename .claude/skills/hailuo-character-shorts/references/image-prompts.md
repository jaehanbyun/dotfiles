# 이미지 3종 프롬프트

`[캐릭터 명세]`와 `[참조]`는 현재 선택한 인물로 바꾼다. 얼굴형, 눈/눈썹, 헤어 실루엣, 점, 체형, 의상, 장신구를 명세로 적고 공유한다. 기존 완성 참조가 있으면 이를 바탕으로 01을 단순화해도 된다. 체형과 네크라인은 사용자가 지정한 성인 캐릭터와 참조를 따른다.

## 유연한 디자인 기준

핵심 키워드는 **미소녀 · 섹시 · 개성**이다. 여기서 미소녀는 아름다운 애니메이션 미형을 뜻하며 모든 인물은 명확한 20대 성인 여성으로 설정한다.

- 미형의 범위 안에서 눈매·눈썹·얼굴 윤곽·표정과 분위기를 다양하게 설계한다. 동일 얼굴에 머리색만 바꾸는 방식은 피한다.
- 섹시함은 자연스러운 볼륨과 곡선, 옷의 핏과 드레이프, 허리선, 자신감 있는 시선, 자세, 재질 대비로 표현한다. 늘 같은 가슴 크기·네크라인·노출량을 강제하지 않는다. 몸에 맞는 높은 네크라인이나 넉넉한 바지와 크롭 상의도 어울릴 수 있다.
- 개성은 서로 어울리는 특징 몇 가지를 연결해 만든다. 큰 땋은 머리와 오버핏 실루엣, 투톤 컬러와 빈티지 레이어링, 짧은 머리와 매끈한 미래적 패션 등은 예시이지 고정 프리셋이 아니다. 머리 길이·묶는 방식·팔레트·하의·신발·장신구를 자유롭게 선택한다.
- 스트리트, 스포티, 빈티지, 우아한 패션, 미래적 패션 등 콘셉트에 맞게 변주한다. 검은 가죽 재킷·초커·체인·단발·고딕 스타일을 모든 캐릭터에 반복하지 않는다.
- 선화와 기본 화풍도 유연하다. 표현적인 패션 일러스트 선과 넓은 셀 음영, 섬세한 애니메이션 선화, 세련된 반실사 2D 채색 모두 가능하다. 01과 02는 같은 기본 그림에서 채색의 밀도만 달라져야 한다.
- 밝은 흰색/크림 배경, 색면 배경, 간결한 환경 배경을 선택할 수 있다. 따뜻한 역광·어두운 배경·금속 광택을 고정하지 않는다. 상반신 두 장은 배경의 구도도 일치시켜 채색 발전을 읽기 쉽게 한다. 전신 참조에서는 인물의 윤곽이 잘 보이게 한다.

사용자가 승인한 취향 예시가 필요하면 다음 이미지를 열어 확인한다. 외형을 복사하거나 세 예시만 반복하는 프리셋으로 사용하지 않는다.

- [민트 장발과 오버핏 패션](../assets/style-examples/01-mint-braid.png): 풍성한 땋은 머리, 큰 상하의 실루엣, 절제된 색면과 밝은 배경.
- [투톤 헤어와 빈티지 레이어링](../assets/style-examples/02-pink-lime.png): 헤어·원단의 색 대비, 느슨한 아우터, 데님과 장식의 조합, 표현적인 선화.
- [에메랄드 의상과 도시적 분위기](../assets/style-examples/03-emerald-editorial.png): 몸에 맞는 높은 네크라인, 매끈한 재질과 아우터의 대비, 차분하고 자신감 있는 표정, 풍부한 2D 채색.

캐릭터마다 `[캐릭터 명세]`, `[기본 화풍]`, `[배경 설계]`, `[완성 채색 방향]`, `[전신 포즈]`, `[하의·신발 명세]`를 채운다. 매번 모든 변수를 무작위로 바꾸기보다 한 인물로 설득력 있게 조합한다. **새 캐릭터마다 자유롭게 설계하되 한 세트의 세 장은 같은 인물·의상·기본 화풍으로 유지한다.**

## 01 — 담백한 채색 상반신

```text
[캐릭터 명세]의 성인 여성을 표현한 세로 상반신 2D 일러스트 한 장. 외형 참조가 있다면 동일 인물을 유지하고, 취향 참조만 있다면 그 미감을 바탕으로 개성 있는 새 인물을 설계한다. 머리부터 허리 부근까지 담고 얼굴·헤어·의상이 중심이 되게 한다. 아름다운 애니메이션 미형 얼굴, 성인다운 매력과 자연스러운 곡선, 개성 있는 패션과 표정.
[기본 화풍]에 맞는 읽기 쉬운 선화와 명확한 기본색, 절제된 셀 음영. 턱 아래, 앞머리 아래, 목과 옷 주름에 적당한 명암을 넣는다. 복잡한 그라데이션·미세 질감·강한 반사는 완성 단계보다 억제한다. [배경 설계]를 단순한 색과 형태로 표현한다. 스케치가 아니라 담백한 기본 채색이 깔끔하게 끝난 단계다.
성인 1명만 등장. 문자, 로고, 워터마크, 드로잉 앱 UI, 콜라주 없음.
```

## 02 — 화려한 채색 상반신

01을 실제 편집 대상으로 전달한다. 독립적인 새 인물 생성으로 호출하지 않는다.

```text
첨부된 01 상반신 그림의 채색·조명·재질 표현만 완성 단계로 발전시킨다. 얼굴, 표정, 눈의 위치, 신체 비율, 포즈, 카메라, 캔버스 비율, 프레이밍, 머리카락의 흐름, 의상·액세서리 디자인과 위치, 주요 선화는 그대로 고정한다.
[기본 화풍]을 유지하며 [완성 채색 방향]에 맞춰 명암, 색의 깊이, 재질별 표현과 조명을 풍부하게 만든다. 얼굴을 읽기 쉽게 하는 빛, 눈과 머리카락의 세부 표현, 자연스러운 피부 음영, 실제 의상 재질에 맞는 하이라이트를 추가한다. 빛의 색과 방향은 콘셉트에 맞게 선택하고, 매번 금빛 역광이나 모든 소재의 유광 처리를 적용하지 않는다. 같은 배경 구성을 유지하며 채색·조명만 발전시킨다.
새 인물로 다시 그리거나 자세·의상을 바꾸지 않는다. 실사나 3D 렌더로 전환하지 않는다. 한 장만 제공. 문자, 로고, 워터마크, UI 없음.
```

## 03 — 담백한 채색 전신

01을 외형·채색 참조로 전달한다. 02의 광택을 복제하지 않는다.

```text
첨부된 01 이미지의 동일한 성인 캐릭터를 머리부터 발끝까지 완전히 보이는 세로 전신 일러스트로 확장한다. [캐릭터 명세]. 얼굴형, 눈매와 눈 색, 헤어스타일, 체형, 기존 의상·장신구를 유지한다. 보이지 않던 하의와 신발은 [하의·신발 명세]로 일관되게 완성한다.
[전신 포즈]로 캐릭터의 성격과 의상의 실루엣을 드러낸다. 양팔과 다리의 윤곽을 읽기 쉽고 머리와 양쪽 발 주변에 충분한 여백이 있게 한다. 01과 같은 [기본 화풍]의 선화·기본색·절제된 음영으로 표현한다. 02의 강한 광택이나 복잡한 입체 채색은 추가하지 않는다. [배경 설계]를 인물의 전체 형태가 잘 보이게 단순화한다.
성인 1명만 등장. 전신을 자르지 않는다. 여러 시점의 설정화, 문자, 로고, 워터마크, UI 없음.
```
