# Design Research Protocol

## Purpose

Ground design decisions in real product references before implementation.

## Research Order

1. Refero MCP for broad screens and flows.
2. Mobbin for deeper mobile references or regional apps.
3. Open Design or Claude Design for high-fidelity exploration.
4. Save durable references under `docs/design/_references/`.
5. Convert accepted patterns into project design specs.

## Intake

Before researching, define:

- screen or flow
- target user
- primary action
- desired tone
- objections to overcome
- reference apps or competitors

## Output

For each researched flow, capture:

- source
- pattern observed
- why it applies
- what not to copy
- resulting design decision
