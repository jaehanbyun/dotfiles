# AI-Native Workflow

## Roles

Codex:

- implementation
- refactor
- bugfix
- tests
- verification

Design/planning tools:

- design handoff
- visual exploration
- reference research
- ADR drafting

## Handoff

Use:

- `HANDOFF.md` for current state
- `docs/exec-plans/active/` for executable plans
- `docs/design/` for accepted design specs
- `docs/decisions/` for ADRs

## Design Flow

1. Research real product patterns.
2. Write design/spec notes.
3. Implement the approved slice.
4. Verify visually and functionally.

## Guardrails

- Do not let prototype code become production code without review.
- Do not silently resolve conflicts between design docs and implementation.
- Do not add services or secrets without explicit approval.
